# iPhoneTransfer 2.4

Windows 10 / 11 x64용 아이폰 사진·파일 USB 전송 프로그램입니다.
.NET 8 런타임을 포함하여 .NET 별도 설치 없이 실행합니다.
권장: Windows 10 22H2(빌드 19045) 이상 또는 Windows 11, 최신 Apple Devices.
32비트 Windows 및 ARM64 전용 배포는 이 패키지에 포함하지 않습니다.

## 시작하기

1. `iPhoneTransfer-Setup.exe`로 설치하거나 무설치 ZIP을 **전부** 풀고 `실행.bat`를 실행합니다.
2. **연결 센터**에서 Windows, Apple 지원, USB, 신뢰 상태를 확인합니다.
3. Apple 기기 지원이 없으면 **Apple Devices 설치**를 누릅니다.
4. 데이터 전송 가능한 USB 케이블로 연결하고 아이폰을 잠금 해제합니다.
5. 아이폰의 **이 컴퓨터를 신뢰**를 승인하면 자동으로 다시 검색합니다.

## 사진 가져오기

사진 목록 불러오기 → 원하는 사진 선택 → 선택한 사진 가져오기 → PC 저장 폴더 선택.
기본은 원본 그대로 저장하며, 아이폰 원본은 삭제하지 않습니다.
`JPG로 변환`을 선택한 경우 변환 가능한 이미지만 JPG로 저장합니다. 실패하면 원본을 보관합니다.
HEIC/HEIF 사진은 내장 디코더로 썸네일·확대 보기·JPG 변환을 지원합니다. 별도 Windows HEIF/HEVC 코덱은 필요하지 않습니다.
MOV/MP4 영상은 내장 FFmpeg로 대표 프레임을 표시합니다. 더블클릭하면 프레임을 크게 볼 수 있으며, 재생은 원본을 PC로 가져온 뒤 가능합니다.
영상은 AFC 위치 이동과 최대 64 KiB의 부분 읽기로 영상 정보와 첫 프레임만 가져옵니다. 미리보기용 전체 영상 복사나 원본 크기만큼의 임시 디스크 공간은 필요하지 않습니다.
영상 썸네일은 긴 변 640픽셀로 만들고 최근 24개를 메모리에 보관합니다. 같은 영상의 선택·확대 보기에는 캐시를 재사용합니다. 기기·앱·경로·크기·수정 시각으로 구분하며 앱 종료 시 사라집니다.
영상 하나의 미리보기는 USB 읽기 총량 16 MiB를 넘지 않습니다. 이 한도 안에서 썸네일을 만들 수 없으면 미리보기 실패로 표시하고, 전체 영상 복사로 전환하지 않습니다. 명시적인 **가져오기**는 기존대로 원본 전체를 저장합니다.
사진의 임시 미리보기 파일은 완료·오류·취소 시 삭제합니다. 앱 강제 종료 시 남을 수 있으며 원본은 삭제하지 않습니다.
iCloud에만 있는 원본은 먼저 기기에 다운로드해야 합니다.
USB 읽기 오류, 파일 크기 불일치, 취소는 완료로 표시하지 않습니다. 완성된 파일만 최종 이름으로 저장합니다.
동일 이름의 기존 파일은 덮어쓰지 않고 새 이름을 사용합니다.

## 아이폰 연결 시 자동 실행

- 설치 시 **아이폰 USB 연결 시 자동 실행**을 선택하거나 앱 **연결 센터**에서 같은 옵션을 켭니다.
- Windows 로그인 후 알림 영역에서 연결을 기다리며 USB 연결을 5초 간격으로 감지합니다.
- 아이폰을 연결하면 앱 창을 열고, 잠금 해제·신뢰 승인이 완료되면 사진 목록을 자동으로 불러옵니다.
- 창을 닫아도 연결 감지는 계속됩니다. 같은 연결로 창을 계속 다시 띄우지 않으며, 분리 후 다시 연결하면 열립니다.
- 연결 센터에서 옵션을 끄면 로그인 자동 실행과 현재 감지를 함께 끕니다. 알림 영역 메뉴에서 이번 로그인 동안만 감지를 종료할 수도 있습니다.
- 무설치 버전은 압축을 푼 폴더를 유지해야 합니다. 경로를 옮기면 새 위치에서 자동 실행을 다시 켜세요.

## 앱에서 가져오기

**앱 파일** → **파일 공유 앱 목록 불러오기** → 앱 선택 → **앱에서 가져오기** → **앱 파일 불러오기**.

- 기본은 **그리드**이며, 사진·영상 썸네일을 자동으로 불러옵니다. **목록**으로 전환해도 선택은 유지됩니다.
- 사진·영상 선택 시 오른쪽에 미리보기가 표시됩니다. 더블클릭·Enter·**크게 보기**로 확대 창을 열고, 마우스 휠로 확대/축소합니다.
- HEIC/HEIF, JPG, PNG 등 사진과 MOV/MP4 등 영상 대표 화면을 지원합니다. 문서·압축 파일은 아이콘으로 표시하며 PC로 가져와 엽니다. 영상 재생은 가져온 뒤 가능합니다.
- 앱의 미리보기는 해당 앱의 Documents에서 읽습니다. 영상은 필요한 구간만 읽고 썸네일을 재사용합니다. **작업 취소**로 중지할 수 있으며 앱·폴더 변경이나 가져오기 시작 시 이전 미리보기 작업을 취소합니다.
- 폴더를 더블클릭하거나 Enter로 열고, **상위 폴더** 또는 Backspace로 돌아갑니다.
- 파일·폴더를 선택한 뒤 **선택 항목 PC로 가져오기**를 눌러 저장 폴더를 고릅니다. Ctrl/Shift 다중 선택과 모두 선택을 지원합니다.
- 사진뿐 아니라 PDF, EPUB, ZIP 등 앱이 공개한 모든 일반 파일을 가져옵니다. 폴더는 하위 파일과 빈 폴더까지 구조를 유지합니다.
- 아이폰 앱의 원본은 삭제하거나 수정하지 않습니다. 같은 이름이 있으면 번호를 붙이며, Windows에서 사용할 수 없는 이름은 안전하게 바꿉니다.
- 큰 파일은 디스크로 직접 복사합니다. USB 오류·크기 불일치·취소가 발생한 파일은 완료 처리하지 않고 임시 파일을 제거합니다. 이미 완료된 파일은 PC에 남습니다.
- 파일 공유를 허용한 앱의 Documents 영역만 지원합니다. 일반 앱 내부 데이터, iCloud에만 있는 파일, 심볼릭 링크는 가져오기 대상이 아닙니다.

## 앱으로 보내기

**앱 파일** → 파일 공유 앱 목록 불러오기 → 앱 선택 → **앱으로 보내기** → 파일 추가/끌어놓기 → 선택한 앱으로 보내기.
아이폰에 설치된 파일 공유 지원 앱의 Documents 폴더로 전송합니다. 사진 앱 카메라롤로 직접 넣는 기능은 아닙니다.
전송은 임시 이름에 기록한 뒤 크기를 확인해 확정하며, 기존 파일과 같은 이름이면 번호를 붙입니다.
연결이 끊겨 아이폰에 접근할 수 없으면 전송 중이던 `.iPhoneTransfer-*.partial`이 남을 수 있습니다.

## 연결 센터와 설치

- 8초 간격 자동 검색. 검사 프로세스는 22초 제한으로 느린/응답 없는 드라이버를 분리합니다.
- Apple Devices 설치: 정확한 Microsoft Store 제품 ID `9NP83LWLPZ9K`를 이용합니다.
  winget을 사용할 수 없거나 설치에 실패하면 공식 Store 페이지를 엽니다. 페이지를 연 것만으로 설치 완료로 표시하지 않습니다.
- 드라이버·서비스 복구: UAC 승인 후 기존 Apple Mobile Device Service 시작/재시작,
  설치된 `usbaapl64.inf` 재등록, 지원 OS에서 USB 재검색을 수행합니다. 다른 USB 드라이버를 삭제하지 않습니다.
- 대체 iTunes 설치: Apple Devices가 없는 환경에서만 실행합니다. winget `Apple.iTunes`를 우선 사용하고,
  없으면 Apple 공식 서버에서 다운로드하여 유효한 Apple 디지털 서명을 확인한 뒤 설치합니다.
- 설치 종료 코드, 취소, 재시작 필요 상태를 구분하고 실제 연결을 다시 검사합니다. 자동 재부팅하지 않습니다.
- 드라이버 설치에는 인터넷과 관리자 승인이 필요할 수 있습니다. Store 정책이나 방화벽, 케이블/포트 고장은 앱이 우회하지 못합니다.

Apple Devices가 설치되어 있으면 전통적인 Apple Mobile Device Service가 없어도 정상일 수 있습니다.
장치 관리자, Windows 업데이트, Apple 공식 도움말, 식별번호를 제외한 진단 보고서 저장을 화면에서 사용할 수 있습니다.
로그: `%LOCALAPPDATA%\iPhoneTransfer\Logs`.
iTunes 다운로드 캐시: `%LOCALAPPDATA%\iPhoneTransfer\InstallerCache`.

## 검증 범위

2.1 검증: 공개 HEIC 예제의 썸네일·확대 보기·JPG 변환, EXIF 회전, 합성 H.264/HEVC MOV의 프레임 추출,
취소 시 디코더 종료, 연결/재연결/중복/오류 시 자동 실행 판정, UI 렌더링과 상태를 검사합니다.
가짜 USB 오류·취소·부분 쓰기·이름 충돌·여러 DCIM 폴더의 대문자 HEIC/MOV 원본 탐색 테스트를 포함합니다.
2.2 검증: 파일·하위/빈 폴더 가져오기, Windows 이름 호환, 중복 이름·선택 처리, 크기 불일치·취소·USB 오류·경로 이탈 차단을 검사했습니다.
Windows 11에 연결된 아이폰에서 공유 앱 13개 탐색, 1개 앱의 Documents 조회, 217,574바이트 파일 가져오기를 실제로 수행했습니다.
같은 원본을 두 번 읽어 SHA-256 일치와 크기를 확인했고, 임시 검증 복사본은 제거했습니다. 아이폰 원본은 변경하지 않았습니다.
2.3 검증: 앱 사진·영상 그리드, 오른쪽 미리보기, 보기 전환 시 선택 유지, 최소 창 크기, 취소·앱 변경 뒤 늦게 도착한 이미지 차단을 검사했습니다.
실제 연결된 아이폰의 파일 공유 앱에서 MOV(217,574바이트)와 JPG(1,945바이트)를 읽어 대표 화면을 생성했습니다.
2.4 검증: 뒤에 영상 정보(moov)가 있는 512 MiB MOV 합성 사례에서 H.264는 131,945바이트, HEVC는 134,387바이트만 읽어 썸네일을 생성했습니다. 4 GiB를 넘는 위치 이동, USB 오류, 취소, 16 MiB 한도와 전체 복사 경로 차단도 검사했습니다.
실제 아이폰 앱 영상 2,628,691,916바이트 중 1,349,609바이트(0.051%), 카메라 영상 30,450,770바이트 중 346,443바이트(1.138%)만 읽었습니다. 같은 영상의 확대 요청은 두 경우 모두 USB 추가 읽기 0바이트였습니다. 파일 구조에 따라 필요한 읽기 용량은 달라집니다.
Windows 10 실제 PC/가상머신, ARM64, 모든 iOS 버전, 드라이버 없는 새 PC 설치, 실제 아이폰 업로드는 별도 검증 대상입니다.
어떤 케이블/기기/보안 정책에서도 연결을 100% 보장한다는 의미는 아닙니다.

## 개발

`dotnet build iPhoneTransfer.sln -c Release`
`dotnet run --project iPhoneTransfer.Tests -c Release`
`powershell -ExecutionPolicy Bypass -File build-dist.ps1`

배포 스크립트는 고정된 빌드 폴더에서 검증한 후 dist를 교체합니다. 최신 배포와 이전 배포 두 개까지만 보관합니다.
소스가 GitHub에 백업된 상태에서만 배포 교체 및 이전 결과 정리를 수행합니다.
HEIC/영상 검증: 게시된 `iPhoneTransfer.exe --media-check <결과 폴더>`.
UI 검증: `iPhoneTransfer.exe --ui-check <결과 폴더>`.
실제 앱 가져오기 검증: `iPhoneTransfer.exe --app-files-check <결과 폴더>` (아이폰 연결 필요, 작은 파일 하나를 임시로 두 번 복사한 후 제거).
실제 앱 미리보기 검증: `iPhoneTransfer.exe --app-media-check <결과 폴더>` (아이폰 연결 필요, 제한된 하위 폴더에서 사진·영상 각 하나를 읽어 임시 미리보기 생성 후 제거).
영상 부분 읽기 검증: `iPhoneTransfer.exe --video-ranges-check <결과 폴더>` (아이폰 연결 필요, 카메라·앱 영상의 실제 읽기 바이트와 재사용 시 추가 읽기 0바이트 확인).

부분 읽기 구현 참고: [libimobiledevice AFC seek](https://docs.libimobiledevice.org/libimobiledevice/latest/afc_8h.html), [FFmpeg HTTP range options](https://ffmpeg.org/ffmpeg-protocols.html#http). FFmpeg 연결은 임시 포트의 127.0.0.1 내부 연결이며 외부 서버를 사용하지 않습니다.
libimobiledevice 및 의존 DLL은 iMobileDevice-net 1.3.17에서 제공됩니다.
