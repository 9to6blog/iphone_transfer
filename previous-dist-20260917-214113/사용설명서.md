# iPhone 사진 전송기 (iPhoneTransfer)

Windows에서 아이폰과 사진/파일을 USB로 주고받는 프로그램입니다.

- **📥 가져오기 (iPhone → PC):** 카메라롤(DCIM)의 사진·영상을 PC 폴더로 복사
- **📤 보내기 (PC → iPhone):** **파일 공유를 지원하는 설치 앱**을 비동기로 조회 → 앱을 선택 → 그 앱의 `Documents` 폴더로 파일 전송

> 애플은 제3자가 카메라롤에 직접 사진을 "넣는" 것을 막아두었기 때문에,
> 보내기는 **파일 공유(File Sharing)를 지원하는 앱**(예: VLC, Documents by Readdle,
> Infuse, KMPlayer 등)을 통해 그 앱의 문서 영역으로 전달하는 방식을 사용합니다.

---

## 기술 구성

| 부분 | 내용 |
|------|------|
| 언어/런타임 | C# / .NET 8 (WPF GUI) |
| 기기 통신 | [libimobiledevice](https://libimobiledevice.org) (`iMobileDevice-net` 바인딩) |
| 가져오기 | AFC(Apple File Conduit)로 `/DCIM` 탐색·복사 |
| 앱 목록 | `installation_proxy`로 설치앱 조회 후 `UIFileSharingEnabled` 필터 |
| 앱 전송 | `house_arrest`(VendDocuments) + AFC로 `/Documents`에 쓰기 |

```
iPhoneTransfer.Core/   ← 기기 통신 로직 (재사용 가능 라이브러리)
iPhoneTransfer.App/    ← WPF 화면
build-dist.ps1         ← 배포 패키지 빌드
install-prerequisites.ps1 ← Apple USB 드라이버 설치 도우미
```

---

## 빌드 (개발자용)

```powershell
dotnet build iPhoneTransfer.sln -c Release
dotnet run --project iPhoneTransfer.App
```

## 배포 패키지 만들기 (다른 PC 배포용)

```powershell
powershell -ExecutionPolicy Bypass -File .\build-dist.ps1
```

`dist\` 폴더와 `iPhoneTransfer-dist.zip`이 생성됩니다. .NET 런타임이 내장되어
**대상 PC에 .NET을 설치할 필요가 없습니다.**

## 사용법 (사용자용)

### 1. 사전 준비 (PC마다 한 번)
아이폰과 USB로 통신하려면 **Apple Mobile Device Support 드라이버**가 필요합니다.
- `install-prerequisites.ps1` 실행 → 'Apple Devices' 앱 또는 iTunes 설치
- 아이폰을 USB로 연결하고, 아이폰 화면의 **"이 컴퓨터를 신뢰"**를 누릅니다.

### 2. 실행
- `실행.bat` (또는 `iPhoneTransfer\iPhoneTransfer.exe`) 더블클릭
- 상단에서 기기를 선택 (안 보이면 **🔄 새로고침**)

### 3. 가져오기
1. **사진 목록 불러오기**
2. 원하는 항목 체크 (또는 **모두 선택**)
3. **선택 항목 PC로 가져오기** → 저장 폴더 지정

### 4. 보내기
1. **파일 공유 앱 목록 불러오기** (비동기 조회)
2. **보낼 앱** 선택
3. 파일을 끌어다 놓거나 **파일 추가**
4. **선택한 앱으로 보내기** → 아이폰에서 해당 앱을 열어 확인

## 자주 묻는 문제

- **기기가 안 보여요:** 아이폰 잠금 해제 → "신뢰" 확인 → 케이블/USB 포트 교체 →
  드라이버 재설치(`install-prerequisites.ps1`). Microsoft Store판 iTunes로 인식이
  안 되면 apple.com의 **데스크톱판 iTunes**를 설치하면 드라이버 호환성이 가장 좋습니다.
- **보내기에서 앱이 안 떠요:** 파일 공유를 지원하는 앱(VLC 등)이 설치돼 있어야 합니다.
- **가져온 사진이 0개:** 기기가 잠겨 있으면 DCIM 접근이 막힙니다. 잠금 해제 후 다시 시도.
